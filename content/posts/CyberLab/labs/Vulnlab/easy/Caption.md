### How to use Grep - Match

{{< toggle "Tag 🏷️" >}}

{{< tag "Burpsuite-intruder-Grep" >}} teach how to use the Grep in the Intruder to add the row to show you want.

{{< /toggle >}}

1. Go back to your main **Intruder** configuration tab (before starting the attack) and click on the **Settings** tab on the far right.
2. Scroll down to the **Grep - Match** section.
3. Click **Clear** to remove the default list of error messages (like "Error", "Exception", etc.).
4. Type `127.0.0.1` into the input box and click **Add**.
5. Make sure the checkbox for **Search responses only** (or similar wording, usually default) is checked.
